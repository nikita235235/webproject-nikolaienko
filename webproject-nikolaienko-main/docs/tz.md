# Технічне завдання: Каталог кросівок "SneakerDrop"

## 1. Опис проєкту
**Назва застосунку:** SneakerDrop
**Призначення:** Веб-застосунок для пошуку, перегляду та збереження у "Вибране" оригінальних моделей кросівок.
**Цільова аудиторія:** Молодь, спортсмени та снікерхеди, які шукають якісні кросівки.

## 2. Ролі та функційні вимоги
**Ролі користувачів:**
1. **Гість** — переглядає асортимент. Доступні лише публічні сторінки.
2. **Користувач** — авторизований, може зберігати цікаві моделі.
3. **Адміністратор** — керує контентом (додає та видаляє товари, бренди).

**Функційні вимоги:**
1. Гість може переглядати загальний список кросівок (Обов'язкова).
2. Гість може фільтрувати кросівки за брендом (Обов'язкова).
3. Гість може переглядати детальну сторінку кросівок (Обов'язкова).
4. Гість може зареєструватися в системі (Обов'язкова).
5. Користувач може авторизуватися в системі (Обов'язкова).
6. Користувач може додавати кросівки до списку "Вибране" (Обов'язкова).
7. Користувач може видаляти кросівки зі списку "Вибране" (Обов'язкова).
8. Користувач може переглядати свій список "Вибране" в кабінеті (Обов'язкова).
9. Адміністратор може додавати нові моделі кросівок у каталог (Обов'язкова).
10. Адміністратор може видаляти кросівки з каталогу (Обов'язкова).

**Нефункційні вимоги:**
1. Продуктивність: Сторінка каталогу завантажується не довше ніж за 2 секунди.
2. Безпека: Паролі зберігаються виключно у вигляді хешів.
3. Адаптивність: Інтерфейс коректно відображається на мобільних пристроях.

## 3. Карта сайту та користувацькі сценарії
**Карта сайту:**
- Головна сторінка / Каталог (Гість, Користувач, Адмін) — Захищений: Ні
- Картка товару (Гість, Користувач, Адмін) — Захищений: Ні
- Реєстрація / Вхід (Гість) — Захищений: Ні
- Кабінет: Вибране (Користувач, Адмін) — Захищений: Так
- Додавання товару (Адмін) — Захищений: Так

**Користувацькі сценарії:**
- **Гостя:** Відкриває каталог → фільтрує за брендом "Nike" → натискає на картку товару → натискає "Додати у вибране" → система просить авторизуватися.
- **Користувача:** Авторизується → відкриває каталог → натискає іконку "сердечко" на кросівках → переходить на сторінку "Вибране" → бачить товар.
